# Стальной рубеж: 1936 — решения по механикам

Оригинальная браузерная стратегия о Второй мировой. Приоритет: **война и фронт**.
Порядок работ: механика → затем текстуры, фото техники, флаги и картинки фокусов (объёмный интерфейс).

| Механика | Решение |
|---|---|
| Режим | Одиночная игра, любая страна, остальные под ИИ |
| Время | Старт 1 января 1936, час — бой и движение, день — экономика. Без конца |
| Вне карты | Колониальный доход (ресурсы, люди), ленд-лиз США событием |
| Идеологии | 4 с партиями. Заложено расширение: гражданские войны, неисторические пути, формируемые страны |
| Формируемые | ЕС (Франция/Нидерланды/Бельгия): демократия, Франция, Германия, Италия, Бенилюкс у тебя или в фракции; члены фракции могут войти добровольно. Рим (Италия): постепенная «национализация» регионов решениями. Награда: новая страна, цвет, название, претензии, бонусы |
| Законы | Призыв, экономика, торговля, пресса, образование |
| Советники | Политические, начальник штаба, конструкторские бюро |
| Постройки | Гражд./воен. заводы, верфи, дороги, форты, ПВО, аэродромы, синтетика |
| Склад | Общий тип снаряжения со средним качеством |
| Торговля | Ручные сделки за гражданские заводы |
| Исследования | 1936–1941, 3+2 слота, штраф за опережение; доктрины — пути за опыт |
| Дивизии | Конструктор как в жанре: сетка 5×5 + 5 поддержки; выбор места развёртывания |
| Бой | Организация/прочность, атаки, броня, ширина, местность, реки, форты, резервы |
| Окружение | Только уничтожение, без трофеев и пленных |
| Командование | Ручное движение, армии, фронт, стрелка; генералы с навыками и чертами |
| Снабжение | Дальность и дороги от столицы, городов и портов |
| Погода | Сезоны и широта |
| Оккупация | Шкала сопротивления |
| Авиация | Зоны и основные миссии, без конструктора |
| Флот | Готовые типы, модули в исследованиях, автобой, приказы: патруль, рейды, база |
| Десант | Подготовка и господство на море, конвои не считаются |
| Дипломатия | Отношения, гарантии, пакты, доступ, фракции, обоснование, напряжённость, ленд-лиз, добровольцы |
| Мир | Мирная конференция: ручной выбор штатов на карте за очки |
| Фокусы | Общее дерево, 40–50 узлов с идеологическими развилками |
| История | ИИ идёт по истории, но гибко |
| Прочее | 3 сложности, всплывающие подсказки, сохранения и автосейв |
